# Changelog

All notable changes to `@poluru-labs/multiselect-kit` are documented in this file.

## [Unreleased]

### Added

- Bootstrap 5 example (`examples/bootstrap/index.html`) that themes `ms-multiselect` with Bootstrap form tokens

## [1.0.0] — 2026-08-22

### Added

- Initial public release of `ms-multiselect`
- Multi-select and single-select modes, search, groups, chips, max selected, loading/empty states
- Keyboard and ARIA combobox / listbox support
- CSS custom properties, `::part` styling, optional `renderOption` hook
- ESM TypeScript package with Storybook and Vitest coverage
