Framework examples for `@poluru-labs/multiselect-kit`.

These snippets are not standalone apps. Copy them into a React, Vue, Angular, Svelte, Bootstrap, or Tailwind project after `npm install @poluru-labs/multiselect-kit`.

- `html/index.html`
- `bootstrap/index.html` — Bootstrap 5 form, CSS tokens, native `<select multiple>` comparison
- `tailwind/index.html` — Tailwind CSS form, CSS tokens, native `<select multiple>` comparison
- `react/MultiselectExample.tsx`
- `vue/MultiselectExample.vue`
- `angular/multiselect-example.ts`
- `svelte/MultiselectExample.svelte`

Preview from the kit root:

```bash
npm run dev
```

Then open:

- http://localhost:5173/examples/bootstrap/index.html
- http://localhost:5173/examples/tailwind/index.html
