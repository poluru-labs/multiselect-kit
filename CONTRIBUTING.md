# Contributing

Thanks for helping improve `@poluru-labs/multiselect-kit`.

```bash
git clone https://github.com/poluru-labs/multiselect-kit.git
cd multiselect-kit
npm install
npm run storybook
```

Node.js 20+ is required.

| Command | Purpose |
| --- | --- |
| `npm run dev` | Vite playground |
| `npm test` | Vitest |
| `npm run typecheck` | TypeScript |
| `npm run build` | Library bundle |

Keep changes focused. Add or update tests for selection, keyboard, and accessibility behavior. Run `npm run verify` before opening a PR.
